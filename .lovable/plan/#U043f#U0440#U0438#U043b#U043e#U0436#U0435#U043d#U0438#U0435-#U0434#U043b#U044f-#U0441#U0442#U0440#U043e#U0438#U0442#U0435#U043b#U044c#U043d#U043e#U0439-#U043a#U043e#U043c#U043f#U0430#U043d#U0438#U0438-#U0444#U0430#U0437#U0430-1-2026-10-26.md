# Приложение для строительной компании — Фаза 1

## Текущее состояние проекта
1. Реализовано: ничего, это чистый шаблон (пустая стартовая страница).
2. База данных и сервисы: не подключены.
3. Для Фазы 1 не хватает: базы данных, входа в систему, ролей, управления работниками.

## Что будет сделано в Фазе 1
- Подключить Lovable Cloud (единое решение: база, вход, файлы).
- Дизайн: интерфейс на испанском, евро, Europe/Madrid, даты DD/MM/YYYY; строгий «строительный» стиль (графит + оранжевый сигнальный акцент), удобный на телефоне.
- Вход по email и паролю, восстановление пароля (страница сброса пароля).
- Первый зарегистрированный пользователь становится владельцем компании; дальше открытая регистрация закрыта — работников создаёт только владелец.
- Раздел «Trabajadores»: владелец создаёт, редактирует, деактивирует и удаляет учётные записи (до 15), задаёт права «может вносить расходы» и «может вносить материалы».
- Каркас навигации со всеми разделами (Inicio, Calendario, Trabajos, Clientes, Obras, Trabajadores, Materiales, Gastos, Finanzas, Presupuestos, Facturas, Equipos, Configuración); ещё не готовые разделы помечены «Próximamente» — без фальшивой функциональности.
- Раздел «Configuración»: реквизиты компании (заполняет владелец, ничего не выдумываем).
- Документы: PROJECT_STATUS.md, SETUP.md, DATABASE.md, .env.example, CHANGELOG.md.

## Техническая часть
- Таблицы: `companies` (задел под несколько компаний), `profiles` (company_id, имя, телефон, активен), `user_roles` (owner/worker, отдельная таблица + функция `has_role`), `worker_permissions`, `audit_log`.
- Все данные изолированы по `company_id` через RLS; проверки прав на сервере, а не только скрытием кнопок.
- Создание/удаление работников — серверные функции с проверкой роли владельца и лимитом 15.
- Тесты на правила: лимит 15 работников, работник не может управлять аккаунтами.
